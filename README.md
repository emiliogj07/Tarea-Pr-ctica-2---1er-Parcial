# Tarea-Pr-ctica-2---1er-Parcial

# Calculadora Matemática

Práctica del primer parcial de Programación 1 del ITLA, desarrollada en Java.

## Funciones
- Sumar dos números.
- Restar dos números.
- Multiplicar dos números.
- Dividir dos números.
- Evitar la división entre cero.

## Herramientas
- Java
- Apache NetBeans

## Cómo utilizar
1. Abrir el proyecto en NetBeans.
2. Ejecutar `Practica.java`.
3. Ingresar dos números.
4. Seleccionar la operación deseada.
